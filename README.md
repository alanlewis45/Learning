# 📚 Study Resources & Notes

Welcome to my study repository! This space is dedicated to sharing educational resources, notes, and practice materials with anyone who needs them.

My goal is to make learning easier by providing organized access to study materials. Whether you are preparing for exams or just revising concepts, I hope these files help you out.

## 🎯 Purpose

I created this repository to:
1.  **Help Others:** Share knowledge freely with peers and juniors.
2.  **Centralize Resources:** Keep all important study materials in one accessible place.
3.  **Collaborate:** Allow others to benefit from these notes.

## 🔄 Updates

I believe in continuous learning and sharing. **I will try to update this repository as often as possible** (ideally daily) with new notes, PDFs, and resources as I progress through my syllabus.

*   **Last Updated:** Check the commit history or the file dates!
*   **Stay Tuned:** Keep an eye out for new uploads.

## 🤝 How to Use These Resources

1.  Click on the file you want to view.
2.  Click the **"Download"** button (usually a downward arrow icon) to save the PDF to your device.
3.  Open and start studying!
